# Devin project config — api-sentinel-forge

API reliability, runtime intelligence and incident investigation.

- CLI: `api-sentinel` (see AGENTS.md for the operating contract).
- Obsidian export: `api-sentinel obsidian status|scan|preview|sync-plan|history` (read verbs pre-allowed in `config.json`; `export`/`export-note` mutate the vault and stay gated).
- `config.json` only declares `permissions` (repo-declarable keys); user-level settings are out of scope.
